# Interface du Grand Cinéma

Interface React du Grand Cinéma, pour les spectateurs et le personnel.

Depuis ce dossier :

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

Le serveur Symfony doit aussi être démarré pour charger la programmation.

Les étapes d’installation et les commandes de test sont détaillées dans le [README du projet](../README.md).
